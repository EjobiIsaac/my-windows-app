# ABRA FINANCES 🇺🇬 - BIG ENTERPRISE v2.0

Windows Desktop App for Microfinance - Uganda Edition

## Features
- Client Management with Photo & Guarantor (KYC)
- Loan Engine: Daily/Weekly/Monthly + Interest + Penalty
- Collections with MTN MoMo / Airtel Money
- Cash Book & Audit Trail
- Manager Reports & Excel Export
- Receipt Printing
- Staff Roles: Manager / Cashier / Loan Officer

## Login
- PIN: `1234`
- Roles: Manager (Full), Cashier (Collections), Loan Officer (Clients)

## How to Build EXE
1. Push to main branch
2. GitHub Actions builds ABRA-FINANCES-v2.0.exe
3. Download from Actions -> Artifacts
4. Run on any Windows PC (no Python needed)

## Tech
- Frontend: HTML/CSS/JS (offline, localStorage)
- Wrapper: Python + pywebview
- Build: PyInstaller
